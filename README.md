# Smart Student Performance Predictor

A Machine Learning project built using Python and Streamlit.

## Features
- Student performance prediction
- Study hours, previous marks and attendance inputs
- Performance visualization
- Sample dataset viewer

## Technologies
- Python
- Pandas
- Scikit-learn
- Streamlit
- Plotly

## Algorithm
Linear Regression

## Run Project
pip install -r requirements.txt

streamlit run app.py
